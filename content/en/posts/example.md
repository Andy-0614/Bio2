## Image Size

Native Markdown images `![Xiaobao](/example.jpg)` can't be resized. Use the HTML `<img>` tag and set `width` instead.

```html
<img src="/example.jpg" alt="Xiaobao" width="30%">
```

<img src="/example.jpg" alt="Xiaobao" width="30%">

## Text Color

Markdown has no syntax for color. Use the HTML `<span>` tag instead.

```html
<span style="color:#c9a227">Vanilla</span>

<span style="color:#5a8f29">Matcha</span>

<span style="background:#5a8f29;color:white">Matcha ice cream</span>
```
